The Family Lens WordPress Theme

Upload the-family-lens-theme.zip via WordPress Admin > Appearance > Themes > Add New > Upload Theme.

After activation:
1. Set a static homepage if desired under Settings > Reading.
2. Add menus under Appearance > Menus for Primary Navigation and footer areas.
3. Add featured images to posts; the homepage lead story uses the latest post image when available.
4. Replace placeholder social links in footer.php with the live social profile URLs.
5. Connect the newsletter form to your preferred email service/plugin before launch.
